# PS2 / emulator-host route (Black, God Hand, anything PS2)

Researched: 2026-10-02 · Follows the six-point checklist in `2026-10-02-repo-map.md`

## Why old console games are a top-tier host target

- No anti-cheat, no updates — the game binary is frozen, so reverse-engineered
  memory maps NEVER rot (modern online games invalidate offsets every patch).
- Cheat databases (pnach / CodeBreaker / ARMax / gamehacking.org) are decades of
  crowdsourced reverse engineering: player coords, HP, gold, camera addresses.
- The emulator is the host platform, and the big ones are open source.

## Verified building blocks

- PCSX2 = GPL open source. Lua-scripted forks exist with memory R/W + pad I/O:
  taba256/PCSX2-rr-lua, gocha/pcsx2 (lua branch).
- God Hand pnach cheats document health / gold / orbs / tension addresses
  (scribd 654346887, cheathappens 12724) — per-game memory maps pre-solved.
- OpenGOAL: Jak & Daxter trilogy decompiled + recompiled to native PC
  (bring-your-own-ISO) — proves the decomp route on PS2, only for Jak so far.

## Four routes, ranked

1. **Asset rip → voxelize → Minecraft** (offline, works today):
   Noesis / Ninja Ripper on emulator → binvox/Minecraftify → Amulet-Core writes.
   Black's levels as MC maps; God Hand models exist on The Models Resource.
2. **PCSX2 bridge** (live, SkyCraft-style): mod a PCSX2 fork to open SkyCraft's
   shared-memory protocol. ONE bridge for all PS2 games; per game only an
   address/config file. Input + overlay are emulator-level (easy); puppeting and
   NPC damage are cheat-address writes; collision export is the hard per-game
   work (PS2 streams geometry via DMA).
3. **Cheat Engine on the PCSX2 process**: no fork, but session-fragile offsets.
   Use for address discovery only.
4. **Decomp/recompile (OpenGOAL route)**: gold standard, years of work per game;
   exists only for Jak & Daxter on PS2. Not near-term for Black/God Hand.

## Six-point checklist, PS2 edition

| Checkpoint | Status |
|---|---|
| Input interception | trivial (emulator pad I/O) |
| Overlay injection | easiest of any host (we own the renderer source) |
| Player puppeting | proven by teleport/moonjump cheats |
| NPC read/damage | proven by HP/gold/enemy cheats |
| Camera override | camera cheats exist for many games |
| Collision export | hard, per-game (DMA streaming) |

## Game verdicts

- **God Hand** — best first PS2 target: small arenas (tractable collision
  export), brawler combat maps to MC melee, memory map already documented.
- **Black** — better as route 1: appeal is the levels; scripted FPS AI would
  fight a live bridge. Note: also on Xbox → xemu (open source) as alternative.

## Why no OpenGOAL-style decomp for Black / God Hand

NOT encryption — PS2 code is unencrypted (disc auth wobble ≠ crypto). Barriers:
1. Labor: MIPS R5900 asm, no symbols, manual C++ recovery; decomp projects take
   years even for smaller games (SM64).
2. Fandom size: decomps need a critical mass of skilled RE volunteers devoted to
   that one game; Jak had it, Black/God Hand don't.
3. Jak's advantages: GOAL (Lisp) had rich runtime metadata → custom decompiler
   was feasible; Jak was also hard to emulate, motivating native recompiles.
   Black/God Hand emulate fine → little incentive, and C++ carries no metadata.

## Cheat Engine vs stable addresses

- Volatility is a HOST-process property (Windows ASLR on the emulator exe).
- Inside emulated PS2 RAM there is NO ASLR: addresses are stable forever —
  God Hand pnach codes from 2006 still work (e.g. damage patch @2012C290).
- CE on the emulator process = address discovery only; pnach = durable mod form.
- Damage rebalancing per platform: Minecraft → Fabric mod/datapatch (JVM heap
  moves under CE); old FPS → source-port defs / AMX/SourceMod; Skyrim-like →
  GMST settings (fDiffMultHPToPC / fDiffMultHPByPC) or mods, CE redundant;
  PS2 → pnach damage-constant patches.

## Integration with the port plan

A PCSX2 fork would be a second host adapter alongside the SKSE plugin:
shares the vendored protocol header (port/code/vendor/), lives in port/code/.
"Game → Minecraft" (rip/voxelize/streem) and "Minecraft → game" (puppet,
damage) both become possible against the same protocol.

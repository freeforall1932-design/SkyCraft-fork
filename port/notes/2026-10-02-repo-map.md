## Key facts for porting

- **Design principle** (`docs/DESIGN.md` §1): neither game rewritten; two mods only
  translate. Skyrim → Minecraft: world shape + NPC positions + input. Minecraft →
  Skyrim: player state + hits + rendered layers.
- **Scale:** 1 block = 70 Skyrim units; Skyrim Z-up → MC Y-up; custom dimension
  (min_y −2032 / height 4064) to fit Skyrim's vertical range.
- **Fabric side host-specifics are cosmetic:** renaming + scale config would make
  it a generic "guest" mod. Renderer mods (Sodium) are explicitly unsupported
  until upstream's Phase 6; texture packs DO flow through (atlas rebuilt on every
  resource reload, `client/render/SkyAtlas.java`).
- **Host plugin subsystems** (each is a per-engine rewrite):
  WorldExporter (collision), ActorMirror (NPCs), InputBridge (raw input),
  PlayerPuppet, CameraDriver, DamageApplier, Compositor (overlay),
  Dig (destruction via hiding statics), Launcher (bundled Prism).

## Six-point host checklist

A host game needs a mod scene that can do all six:

1. Read collision geometry around the player
2. Puppet the player + disable its own movement
3. Override the camera
4. Intercept raw input
5. Inject an overlay into the rendered frame
6. Read NPCs and apply damage to them

(7th, optional: editable world persistence — needed for digging/destruction.)

## Portability verdicts (discussed 2026-10-02)

| Host | Carries over | Notes |
|---|---|---|
| Enderal SE / Skyrim-engine TCs | ~95–100% | Same runtime, same SKSE |
| Fallout 4 | ~50–60% | CommonLibF4 mirrors CommonLibSSE APIs; scale differs (~1 unit ≈ 1 cm) |
| Starfield | ~20–30% | CE2 concepts map; young script-extender ecosystem |
| Oblivion classic / Morrowind | ~25–40% | Old Gamebryo; OBSE/MWSE thinner; physics stack primitive |
| Unity host | architecture + fabric + protocol only | BepInEx/MelonLoader can satisfy all six points |
| Unreal host | same, harder | UE4SS; camera/overlay fight the engine |
| Online/anti-cheat games | ❌ | Memory hooks = bans. Clean-room rewrite (à la author's 2010 Rust Rewrite Mashup) is the only route |

In all cases: `protocol/` ~90%, `fabric/` ~85%, `skse/` equivalent = from scratch.
